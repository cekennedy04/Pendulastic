* **Errors & Troubleshooting:**
  * **Spec §3.2 defect caught at planning time (`1bea6ca`):** the original spec reused `is_stationary_window` as the settle test. Two independent problems: (1) its own doc comment records that strapped-sensor accel noise routinely exceeds the 0.18 m/s² bound even at rest, so it never fires for a meaningful fraction of genuinely fine trials — combined with the no-cap decision, those trials would have recorded **indefinitely**, and only real hardware would have shown it; (2) `TrialSession` has no accel buffer to feed it anyway. Resolution: gyro-only `recently_calm` against `ZERO_CAPTURE_GUARD_RAD_S` (0.3 rad/s, empirically derived from the reference corpus), plus a dedicated `gyro_settle` buffer because `push()` stops maintaining `gyro_hold` once state is Released.
  * Minor doc drift fixed in passing (`2861c5d`): README said "five sections" after trends made six, and an earlier insertion had orphaned the MAS-drafts paragraph.
* **Key Learnings:**
  * Five seconds of settle isn't arbitrary: `neutral_deg` is the settled-tail median and every angle (including `a0_deg`) is expressed relative to it, so tail length directly shifts the whole waveform. That's also why `capture_protocol_version` exists — longitudinal analysis must not silently mix operator-terminated and settle-terminated recordings.
  * A doc comment paid for itself: the empirical never-fires note on `ZERO_CAPTURE_GUARD_RAD_S` is what turned a field-only defect into a planning-time catch.
  * Charts encode epistemics: session medians because single-trial discrimination measures worse than chance; pending MAS as a gap because zero means "no spasticity", the opposite of "not assessed"; no trend lines or zone shading because each would assert an interpretation the app suppresses everywhere else.
  * Versioning by absence (missing field ⇒ protocol 1) keeps every historical manifest valid while still fencing the new regime.
