* **Key Learnings:**
  * Don't trust reference decoder code — verify byte order and channel stride from the data itself (the MATLAB snippet would have silently misread every trial).
  * MATLAB porting fidelity matters down to quirks: `tnormt`'s asymmetric 150/151-sample baseline windows and the normalized `Wn=10/250` cutoff were preserved exactly.
  * Without a `.gitattributes`, line-ending state is per-machine (`core.autocrlf`); pinning it is the only way to make checkouts reproducible across the Windows lab machine and CI.
