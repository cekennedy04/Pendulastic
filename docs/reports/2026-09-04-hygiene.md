14. `[Doc Drift Fix]` **The documented accel-bias formula is the one the code was
    explicitly changed away from.** `ALGORITHM_LAUNCH_CONFIRMATION.md` (Calibration
    Sequence, step 3) and `IMPACT_MEASUREMENT_REPORT.md` (Task 10 Correction
    Mechanism, step 1) both state `bias = mean(raw_accel_buffer) - [0, 0, 9.81]`.
    The live `calibrate_accel_bias()` does neither half of that: it picks `g` from
    the data's own scale (`g = 9.81 if mag > 3.0 else 1.0`, because Sensor Stream's
    iOS build reports g's and its Android build reports m/s2), and it removes
    gravity along the *measured* direction (`gravity = mean_accel * (g / mag)`)
    rather than forcing it onto +Z. The function's own docstring documents the
    `[0, 0, sign*g]` version as a superseded bug that "actively, continuously
    steers the AHRS toward a wrong orientation." This is the most misleading item
    in the set - the docs describe the defect, not the fix.
```bash
sed -n '458,509p' pendulastic_imu_server.py  # then rewrite step 3 in ALGORITHM_LAUNCH_CONFIRMATION.md and the "Task 10 Correction Mechanism" step 1 in IMPACT_MEASUREMENT_REPORT.md to match
```
